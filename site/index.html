Nhà máy phần mềm AI · local-first

Từ một câu mô tả → app chạy thật, có kiểm chứng độc lập.

AREA biến yêu cầu (hoặc lệnh bằng lời) thành phần mềm: sinh spec, khoá bộ test làm oracle TRƯỚC khi code, build tới khi "oracle xanh", chạy các gate bảo mật/E2E/chaos, rồi deploy. Bằng Claude — chạy trên máy bạn, dùng tài khoản của bạn.

requirement / tài liệu / clone → spec → khoá oracle (TDD) → build → gates → deploy

Mô hình

Mọi thứ nằm ở phía bạn. Chi phí vận hành ≈ 0.

Không có server chung, không multi-tenant. Mỗi người chạy AREA trên máy mình với tài khoản của mình — nên cô lập giữa người dùng là tự nhiên, và không ai giữ credential của ai.

Code do AI sinh ra chỉ chạy trên máy của chính người yêu cầu nó — an toàn theo thiết kế. Quyết định kiến trúc đầy đủ: ADR 0001.

Xương sống

Vòng hội tụ theo oracle — không để LLM tự chấm.

Bộ test được một tác nhân độc lập viết và khoá checksum TRƯỚC khi build; tác nhân sửa code không được chạm vào test. Vòng lặp chỉ dừng khi "oracle xanh".

01

Spec

Requirement / tài liệu → spec + acceptance criteria chạy được.

02

Khoá oracle

Viết + khoá holdout độc lập (TDD) làm đích từ iteration 0.

03

Build

Agent build → test → fix, lặp tới khi qua bộ test đã khoá.

04

Gates

Security 2-tầng · E2E (Playwright) · chaos · SLSA provenance.

05

Deploy

Provision + deploy lên Cloudflare/Vercel của bạn, có human gate.

Lệnh

Dùng từ dòng lệnh hoặc dashboard.

area guiDashboard: pipeline trực tiếp + box chat ra lệnh (tự mở trình duyệt).
area run "mô tả app"Yêu cầu bằng lời → app, qua oracle-loop.
area iterate <app> "thêm X"Ra lệnh sửa: gộp vào spec → khoá lại oracle → rebuild.
area export <app> --repo <url> --pushGiao app thành repo git riêng của bạn.
area doctorKiểm tra môi trường local (Python/Node/git/Claude).
area clone <git|url>Reverse-engineer app mẫu → spec → build-to-parity.
Vì sao local-first

Đổi "một URL tiện" lấy an toàn và sở hữu thật.

Cô lập tự nhiên

Không server chung → không cần sandbox multi-tenant. Mỗi người là máy của mình.

Bạn sở hữu tất cả

Workspace, repo (qua area export), và bản deploy đều thuộc tài khoản của bạn.

Không giữ secret của ai

Key Claude và credential deploy không bao giờ rời máy bạn.

Cài đặt

Ba bước, trên máy bạn.

$ git clone <repo> && cd SW_Factory
$ bash scripts/install.sh  # venv + cài + kiểm tra môi trường
$ area gui  # http://127.0.0.1:8787

Rồi đăng nhập Claude của bạn (Claude Code keyless, hoặc export ANTHROPIC_API_KEY=…) và — khi deploy — Cloudflare/Vercel của bạn.
